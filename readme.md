1. Введение в ONEGIN_SORT

Onegin_sort - программа, способная читать текстовый файл, обрабатывать его построчно и выводить текст произведения в различных видах:
(1) - Со строками, отсортированными по алфавиту по началам строк
(2) - Со строками, отсортированными по алфавиту по концам строк
(3) - Со строками, возвращенными в начальное положение



2. Возможности

По ходу решения общей задачи программе приходится решать множество подзадач, таких как:
(1) - Копирование текста в единый буфер, формирующийся по ходу работы программы
(2) - Разбиение текста на строки с заменой '\n' на '\0' непосредственно в буфере
(3) - Регистронезависимая алфавитная сортировка по началам строк
(4) - Регистронезависимая алфавитная сортировка по концам строк
(5) - Вывод результата в файлы
(6) - Сортировка методом quick_sort (см. ниже)

quick_sort - метод рекурсивной сортировки, предложенный Чарльзом Энтони Ричардом Хоаром в 1962 г.
Для заданного массива выбирается один элемент (а в данном случае он выбирается случайным образом), который разбивает остальные элементы на два подмножества - те, что меньше, и те, что не меньше него. Случайный выбор элемента аргументируется в таком случае невозможностью подобрать массив, способный нарочно замедлить выполнение программы (Пояснение: при неслучайном выборе элемента возможно подобрать такой массив, чтобы сравнение постоянно шло с, к примеру, наименьшим элементом массива, что понизит эффективность работы программы, в т.ч. с точки зрения затрачиваемого времени). Та же процедура рекурсивно применяется и к двум полученным подмножествам. Если в подмножестве менее двух элементов, то сортировать нечего, и рекурсия завершается.

Под алгоритм quick_sort было написано несколько компараторов, которые подходят для стандартной функции qsort в C/C++

quick_sort, реализованный в данной программе поддерживает все типы сортируемых данных (как стандартный qsort), очевидно, при реализованных соответствующих компараторах



3. Требования и сборка

Для запуска программы потребуется компилятор языка C/C++ (К примеру, g++/clang++)
Команда для сборки в терминале:
g++ main_onegin.cpp -o onegin.exe
При этом файлы main_onegin.cpp; onegin_string_funcs.cpp; onegin_sorting.cpp должны находиться в одной папке.
Также следует проверить, "находится" ли пользователь в папке, содержащей проект (для windows: ls .). Если нет, то для начала следует перейти в нужную папку



4. Запуск и использование

После сборки следует написать в терминале .\onegin.exe
Во время работы программа потребует от пользователя ввести названия файлов для прочтения и записи текста. При желании можно указать названия файлов перед запуском программы (след. образом: .\onegin.exe onegin_read.txt onegin_write.txt), тогда пользователь сможет получить результат сразу. Результатом будет 4 секции в файле onegin_write.txt



5. Условия для входных данных

(1) - Файлы формата .txt
(2) - Строка - набор символов, не содержащий '\0', оканчивающийся символом '\n'
(3) - Используемые в программе функции воспринимают символы текста побайтово, так что для корректной работы программы следует использовать символы с кодировкой ASCII (Вообще говоря, можно использовать любую кодировку, в которой символ занимает 1 байт, но в таком случае не гарантируется корректная сортировка строк по алфавиту)



6. Архитектура

(1) - main_onegin.cpp - Чтение/запись текста + вызов функций из ниже описанных файлов
(2) - onegin_string_funcs.cpp - Набор функций для различной работы со строками
(3) - onegin_sorting.cpp - Набор функций для сортировки quick_sort (в т.ч. компараторы)



7. Интересные детали работы

(1) - Почему реализованы указатели zero_buffer и buffer = zero_buffer + 1? - Чтобы перед началом первой строки тоже стоял '\0'-барьер для обратного прохода компаратора
(2) - Почему в буфере '\n' заменяются на '\0' - так строки становятся C-строками на месте, без копирования
